# MBTI 语音 Chatflow

系统提示词：`mbti-system-prompt.txt`；会话记忆的用户输入模板：`mbti-query-template.txt`。应用自动播报开场白，用户首次回应后开始提问；问题和解释尽量不超过 20 字，最终报告为完整四维简报。

本地 Dify 应用：`33e61c71-4c9a-4acc-a3bc-e5f1cdd6c0af`（AI面试）。

## 语音打断

`va_dify_azure` 使用 `interrupt_on_partial: false` 和 `asr_final_debounce_ms: 900`。临时识别片段不触发打断；最终识别结果经过合并等待后，停止旧回复并提交新输入。等待期间继续出现识别文本会重新计时，简短的最终回答仍会保留。

该配置需要重新开始语音会话才能加载。其他图默认保留原先的即时打断行为。这是识别结果确认机制，并非声学降噪；被识别为完整文字的背景声音仍可能触发输入。

## 模型设置

为避免影响其他应用，使用独立模型配置 `Qwen3.6-35B-A3B-MBTI`，实际请求模型仍是 `Qwen3.6-35B-A3B`。原模型配置保持不变。

- OpenAI API Compatible 插件：兼容模式 `extended`，思考支持 `supported`。
- LLM 节点：`enable_thinking: false`、`temperature: 0.2`、`max_tokens: 128`。
- 模型只理解当前回答，记忆窗口保留最近 4 轮；12 题答案保存在会话变量 `mbti_state` 中，不依赖历史窗口计数。
- 密钥仅通过本地 Dify 凭据管理与忽略提交的环境配置保存。

仅在提示词里要求“不输出思考”不能关闭服务器推理。插件的 `strict` 模式不会传递关闭思考的扩展参数；专用配置通过 `chat_template_kwargs.enable_thinking=false` 关闭推理。

## 进度、计分与报告

流程为：用户输入 → LLM 理解回答 → 代码维护进度并生成回复 → 保存会话变量 → 输出回复。LLM 返回内部 JSON，不直接展示或播报；代码节点源文件为 `mbti_completion_guard.py`。

`mbti_state` 保存当前题、12 个答案、是否已追问、是否完成及最终报告。有效回答只推进一题；含糊时追问一次，再次含糊或跳过记 X。每维有至少两个有效答案且一方占多数才确定字母，否则 X。四维由程序统计，不让模型重新回顾历史猜测结果。

第 12 题处理后立即生成报告，包含类型、四维倾向及非标准化测评说明。报告不受 20 字限制。完成后“继续”“你好”“扔掉它”等不能回到题目；只有明确的重测指令清空本轮。用户可以查看报告、询问含义，或明确更正已回答的题目。

报告采用四节结构：类型概览、四维倾向与回答依据、日常相处与行动建议、结果说明。展示每维两侧真实题数和未定题数，不使用虚构的标准分、准确率或百分位。历史会话缺少逐题记录时明确注明，不补造依据。查看旧报告时会按现存记录升级为新格式。

前端 `MBTIReport.tsx` 渲染分节卡片。Dify 语音适配层保留报告换行；本图的 `report_tts_summary` 让语音简短提示结束和查看报告，完整报告保留在文字区。其他图该配置默认为空。新开语音会话才会加载更新后的语音控制及换行处理代码。

已结束的旧会话可保留原结果并转换成四维报告；缺失的原始逐题答案不会凭空补齐。

## 验证（2026-09-21）

本地规则测试：

```bash
python3 -m unittest discover -s ai_agents/agents/examples/demo/dify -p 'test_*.py' -v
```

覆盖 16 种类型、票数相同或证据不足、12 题结束报告、含糊及跳过、结果查看、明确重测、答案更正、无效模型输出不推进及完成后防止重复出题。

发布版本 15 的真实接口测试通过：12 个自然语言答案得到预期 INFP 四维报告；随后输入“扔掉它”“继续”“你好”“不要重新测试”均保持结束。报告解释、原报告重看及明确重测后进入第 1、2 题均通过。首个 12 题流程的完整回复耗时中位数 0.70 秒，最长 0.89 秒。

自然语言由模型分类，规则测试不代表所有自然表述都能正确理解。接口耗时不包含语音识别、结束说话判断及语音合成。

版本 17 验证：13 个报告与状态规则测试、5 个语音控制测试通过；实际接口完整 12 题生成详细 INFP 报告，随后查看报告、解释、结束及重测通过。报告本轮生成耗时 0.70 秒，13 轮完整回复中位数 0.72 秒。另验证报告卡片四节渲染、换行经过语音适配层保持完整，以及播报摘要而非整份报告。
